Architecture

Component overview

ComponentResponsibility
ReconciliationIndex Immutable in-memory index built from Tier 1/2/3 result lists. Tier 3 > Tier 2 matched > Tier 1 priority. Provides get(txn_id), filter_by_status(), filter_by_rule(). Never touches the pipeline modules.
classify_intent() Deterministic regex/keyword classifier. Returns one of 7 intent constants plus extracted parameters (transaction_id, rule, status). No LLM. Handles case-insensitive PAY IDs, refund suffixes, phrasing variants.
Answer composers Pure functions over retrieved data — _compose_lookup_answer, _compose_why_answer, _compose_evidence_answer, _compose_filter_answer, _compose_rule_filter_answer. Always produce a valid explanation from structured data alone.
SettlementQAAgent.ask() Classifies → retrieves → composes template answer → optionally asks Gemini to compose prose from the retrieved slice (never the full dataset). Returns QAAnswer with found, supported, llm_used, llm_unavailable flags.
build_qa_agent() Convenience constructor: builds index + agent from raw run_tier1 / run_tier2 / run_tier3 output in one call.

Safety constraints enforced
✓
No second reconciliation engine — Q&A only reads existing Tier 1/2/3 results
✓
Deterministic retrieval first — Gemini is optional prose polish, never a decision-maker
✓
Gemini only receives the retrieved slice for one question — never the full dataset
✓
Missing transaction → "not found", never invented evidence or status
✓
Results are never mutated — index stores serialised dicts, not live objects
✓
MATCHED / HUMAN_REVIEW / UNRESOLVED labels preserved exactly from pipeline
✓
Gemini unavailable → template explanation returned, llm_unavailable=True, no crash
✓
Filter questions (FILTER_STATUS, FILTER_RULE) never consult Gemini
✓
API key read only from os.environ, same as Tier 3 — never hardcoded
✓
Unsupported questions return explicit refusal with supported scope listed
Usage example
from core.match_exact import run_tier1, get_residue
from core.match_fuzzy import run_tier2
from core.match_llm   import run_tier3, GeminiLLMClient
from core.qa_agent    import build_qa_agent

r1, _, matcher = run_tier1(data_dir="data", return_matcher=True)
r2, _          = run_tier2(get_residue(r1), matcher)
r3, _          = run_tier3(r2, matcher, llm_client=GeminiLLMClient())

agent  = build_qa_agent(r1, r2, r3)
answer = agent.ask("What happened to PAY109?")

print(answer.explanation)
# answer.found, .supported, .llm_used, .llm_unavailable, .retrieved_data also available
